Clone
-----

.. tab-set::

    .. tab-item:: MacOS

        .. code-block:: console

            git clone https://github.com/craigfouts/ant-farm.git
            cd ant-farm
            python -m venv .env
            source .env/bin/activate
            pip install -r requirements.txt

    .. tab-item:: Windows

        .. code-block:: console

            git clone https://github.com/craigfouts/ant-farm.git
            cd ant-farm
            python -m venv .env
            .env\Scripts\activate
            pip install -r requirements.txt
